# Pricing Strategy

## Purpose

Pricing must reflect:

- operational value (time saved)
- decision acceleration
- reduced overhead

NOT:
- features
- lines of code
- “AI usage”

---

## Core Pricing Model

### Recommended: Per User + Value Tier Hybrid

Base:
- price per active user (monthly)

Plus:
- tiered value based on capability

---

## Suggested Pricing Tiers

### Starter (Pilot)

- $10–$20 / user / month
- small teams (5–25 users)
- core features:
  - ticketing
  - routing
  - basic AI assist

---

### Professional

- $25–$50 / user / month
- mid-size teams

Includes:
- routing explainability
- workload balancing
- rebalance suggestions
- workflow metrics

---

### Enterprise

- $75–$150 / user / month
- large orgs / departments

Includes:
- advanced metrics
- audit logs
- role configuration
- SLA customization
- priority support

---

## Value Anchoring (CRITICAL)

Do NOT justify pricing with features.

Always anchor to:

- hours saved
- reduced meetings
- faster decisions

---

### Example Framing

"If this saves 1 hour per user per week,  
that’s ~4 hours/month.

At $50/hour cost → $200 saved per user.

Cortex at $25–$50/month is a no-brainer."

---

## Entry Strategy

### First Customers

- discounted or free pilot (2–4 weeks)
- convert based on results

---

## Pricing Mistakes (DO NOT DO)

- ❌ underprice (signals low value)
- ❌ charge for AI tokens
- ❌ complex pricing tiers
- ❌ feature-based pricing

---

## Expansion Strategy

Start with:

- one team
- one department

Expand to:

- multiple teams
- organization-wide rollout

---

## Upsell Levers

- advanced reporting
- enterprise audit features
- SLA customization
- integrations (future)

---

## Golden Rule

Price should feel:

"cheap compared to the time it saves"
